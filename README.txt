Compilador Portugol

Como compilar e executar:
    make
    ./compilador <nome do arquivo de entrada> 

Parte concluida:
    A analise lexica e a analise sintatica estao implementadas. O programa le um arquivo fonte, mostra os atomos reconhecidos e verifica a gramatica.
